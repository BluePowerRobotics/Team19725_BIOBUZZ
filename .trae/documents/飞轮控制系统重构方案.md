# 飞轮（PrototypeShooter）控制系统重构方案

## Summary

按《飞轮系统控制理论研究报告》的最终方案，把 `PrototypeShooter` 从「PIDSVAController 软件速度闭环（输出功率）」改为自包含的简化控制器，直接输出**占空比**：

```
duty = Kff·ω* + Kp·err + Ki·∫err + Vboost
err  = ω* - ω
duty = sat(duty, dutyMin, dutyMax)
```

- 控制律 = **稳态前馈 + PI 反馈 + 掉速检测触发补偿**（完整按报告）。
- `calculate(目标转速, 当前转速) → 占空比`，`dt` 与状态全部由控制器内部维护，调用方不再传 `dt/VelCycle/velocity/acceleration`。
- 增益量纲统一为 **占空比**（不读电压传感器）。
- 明确 I 项的**上限 / 生效节点 / 清零节点**三处语义。

## 控制律执行位置（调用链）

控制律整体封装在 `PrototypeShooter` 内部，`PrototypeShooterTest` 不感知任何中间量：

```
PrototypeShooterTest.runOpMode() 的 while 循环（每帧一次）
        └── shooter.update()                          ← OpMode 里唯一的调用点
                ├── calculate(targetVelocity, motor.getVelocity())   ← 控制律真正在这里算
                │       · 内部用计时器推进 dt、维护 integral / boost 状态
                │       · 前馈 + PI + 掉速补偿 → 返回占空比
                └── motor.setPower(计算结果)
```

- **执行层**：`PrototypeShooter.calculate()`。
- **调用者**：仅 `PrototypeShooter.update()`（每帧一次），`update()` 再由 OpMode 主循环调用。
- **不新增独立控制器类**，OpMode 不直接调用 `calculate`，也不自行 `setPower`。

| 参数 | 默认值 | 单位 | 含义 |
|---|---|---|---|
| `kff` | `0.0002` | 占空比/(tick/s) | 稳态前馈增益，≈ 稳态占空比 / 目标转速 |
| `kp` | `0.00005` | 占空比/(tick/s) | 比例增益 |
| `ki` | `0.00002` | 占空比/(tick/s·s) | 积分增益 |

| `dropThreshold` | `300` | tick/s | 掉速判定 ①：`err > dropThreshold` |
| `dropRateThreshold` | `8000` | tick/s² | 掉速判定 ②：`dω/dt < -dropRateThreshold` |
| `kBoost` | `0.0002` | 占空比/(tick/s) | 掉速补偿增益 |
| `boostMax` | `0.4` | 占空比 | 补偿上限 |
| `boostDurationSec` | `0.3` | s | 补偿持续时长 |
| `dutyMin` | `0.0` | 占空比 | 输出下限（报告：`0 ≤ d ≤ 1`） |
| `dutyMax` | `1.0` | 占空比 | 输出上限 |
| `motorReversed` | `false` | — | 电机方向（装配决定，非标定项） |
| `targetVelocity` | `0` | tick/s | 运行时目标转速 |

**新增运行时状态**

- `double duty`：最近一次下发的占空比（供遥测）
- `double integral`、`double previousVelocity`、`double lastTime`
- `boolean boostActive`、`double boostTimer`

**新增核心方法 `/` 重写 `update()`**

```java
/**
 * 速度环单步计算：输入目标转速与当前转速，输出占空比。
 * 每帧只可调用一次（内部用计时器推进 dt、维护积分与补偿状态）。
 */
public double calculate(double targetVel, double currentVel) {
    double currentTime = now();
    double dt = currentTime - lastTime;
    lastTime = currentTime;
    if (dt <= 0 || dt > 1.0) dt = 0.02;              // 首帧/停顿兜底

    double error = targetVel - currentVel;
    double dVelocity = (currentVel - previousVelocity) / dt;
    previousVelocity = currentVel;

    // ---- 掉速检测与触发补偿 ----
    boolean dropDetected = targetVel != 0
            && (error > dropThreshold || dVelocity < -dropRateThreshold);
    if (dropDetected) {
        boostActive = true;
        boostTimer = 0.0;
        integral = 0.0;                               // 清零节点③：触发补偿时清零
    }
    if (boostActive) {
        boostTimer += dt;
        if (boostTimer >= boostDurationSec || error <= 0) {
            boostActive = false;                      // 恢复到位或超时退出
        }
    }

    // ---- 积分：生效节点 / 清零节点 ----
    boolean iActive = targetVel != 0 && Math.abs(error) < iZone;
    if (iActive) {
        integral += error * dt;                       // 生效节点：目标非 0 且 |err| < iZone
    } else {
        integral = 0.0;                               // 清零节点①②：停机 或 |err| ≥ iZone
    }
    double iTerm = ki * integral;
    if (iTerm > maxI) {                               // 上限：回算限幅防饱和
        iTerm = maxI;
        if (ki != 0) integral = maxI / ki;
    } else if (iTerm < -maxI) {
        iTerm = -maxI;
        if (ki != 0) integral = -maxI / ki;
    }

    // ---- 前馈 + PI + 补偿，输出占空比 ----
    double boost = boostActive ? Math.max(0.0, Math.min(kBoost * error, boostMax)) : 0.0;
    double out = kff * targetVel + kp * error + iTerm + boost;
    if (out > dutyMax) out = dutyMax;
    if (out < dutyMin) out = dutyMin;

    this.duty = out;
    return out;
}

/** 每帧调用：计算占空比并下发给电机。 */
public void update() {
    motor.setPower(calculate(targetVelocity, motor.getVelocity()));
}
```

**I 项三处语义（本方案明确定义）**

| 项 | 规则 |
|---|---|
| **上限** | 对积分项 `ki·∫err` 限幅到 `±maxI`（占空比）；饱和时把 `integral` 回算为 `±maxI/ki`，防止内部无界增长 |
| **生效节点** | `targetVelocity != 0` 且 `\|error\| < iZone` 时才累加积分 |
| **清零节点** | ① `targetVelocity == 0`（停机）；② `\|error\| ≥ iZone`（误差带外）；③ 掉速触发补偿时（避免与 boost 叠加） |

**保留的公共 API**

- 构造 `PrototypeShooter(HardwareMap, Telemetry)`（内部仍 `RUN_WITHOUT_ENCODER` + `FLOAT`）
- `setTargetVelocity(int)`、`stop()`、`getTargetVelocity()`、`update()`、`setTelemetry()`
- 读取方法：`getVelocity()`、`getDuty()`（替代 `getPower()`）、`getError()`、`getCurrent()`
- 新增查询：`isBoostActive()`

**`setTelemetry()` 更新为**

`Shooter target / velocity / error / duty / boost` 五行（`duty` 用 `%.3f`，`boost` 输出 `boostActive` 状态）。

**类注释**：更新为「一阶等效模型 + 稳态前馈 + PI + 掉速检测补偿，直接输出占空比」，并说明参数标定依据报告第 6 章（阶跃辨识 `kff/kp/ki`、稳态波动定 `dropThreshold`、正常减速度定 `dropRateThreshold`、`kBoost≈2~5·kp`）。

## Assumptions & Decisions

1. **就地重写 `PrototypeShooter`**，保留类名、包路径与公共 API（兼容 `PrototypeShooterTest`），不新建类。
2. **增益用占空比单位，不读电压传感器**（用户选定）；前馈与 PI 输出即为占空比，`dutyMin=0 / dutyMax=1`。
3. **补偿只做加速方向**：`boost` 限幅在 `[0, boostMax]`，且退出条件为「持续 `boostDurationSec`」或「误差 `≤0`（已恢复）」。
4. **`calculate` 有状态**：内部用 `System.nanoTime()` 推进 `dt`，每帧只能调用一次；`update()` 是唯一调用点。
5. 旧 `kS/kV/kA` 前馈被 `kff`（对设定值）取代，不再使用 `PIDSVAController`/`SlotConfig`；这些工具类本身保留不动。
6. 表中默认值为待实机标定的**起点**，最终值以 Dashboard 整定为准（报告第 6 章流程）。
