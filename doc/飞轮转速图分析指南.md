# 转速图分析指南

配套三件套：

| 文件 | 作用 |
|---|---|
| `export_clean_table.py` | 把 RC 上导出的**原始** Dashboard 遥测 CSV 处理成可直接画图的**数据表**（严格单调时间轴 + 数值列） |
| `plot_speed.m` | MATLAB 画图 + 统计：`<名>_speed.png`（转速专图）、`<名>_diag.png`（四联诊断图）、`plot_speed_stats.txt` |
| 本文件 | 怎么读这些图、怎么下结论、改哪个参数 |

---

## 0. 三步生成图

```bash
# ① 处理数据（可一次给多个日志）
python tools/tuning/export_clean_table.py "PrototypeShooterTest 2026-09-04 20_55_44.csv" --out ./clean
#    → ./clean/PrototypeShooterTest_2026-09-04_20_55_44_clean.csv
```

```matlab
% ② 画图（MATLAB 里 cd 到 tools/tuning）
plot_speed('C:\path\clean\xxx_clean.csv','-out','C:\path\figs')
plot_speed('xxx_clean.csv')                      % 同目录下第一份
plot_speed({'a_clean.csv','b_clean.csv'})        % 多份叠加比较转速
plot_speed('原始日志.csv')                        % 也可以直接喂原始 Dashboard CSV
plot_speed(F,'-tail',3,'-title','起飞轮 2250')    % 稳态窗口 3 s、自定义标题
```

③ 图与统计在同级目录：`*_speed.png` / `*_diag.png` / `plot_speed_stats.txt`。

**为什么要先"处理"**：原始日志的 `time` 列（`HH:MM:SS.mmm`）**毫秒字段是坏的**，同一秒内会从 ~900 跳回 ~100；按它排序会**伪造出根本不存在的锯齿暴跌**。处理脚本丢弃毫秒、按**行序**重建均匀时间轴（`dt = 跨度/(n−1)`），并把 `error` 统一重算为 `target − velocity`。

## 1. 图上有什么

**`_speed.png`（转速专图，判读主力）**

- 上：**转速**。蓝/彩实线 = 实测 ω，红虚线 = 目标 ω\*，灰竖虚线 = 目标变化点。
- 下：**误差 = 目标 − 实测**。红点线 = ±2% 目标，绿点线 = ±1 个量化台阶。

**`_diag.png`（四联诊断图）**

| 面板 | 内容 | 看什么 |
|---|---|---|
| ① 转速 | 目标 vs 实测 | 跟随、超调、掉速 |
| ② 误差 | 误差 + ±1 台阶线 | 稳态误差是否被台阶限住 |
| ③ 占空比 | duty + FF + I + P（黑点线=限幅前之和） | **谁在主导**；黑点线冲出红上限说明被限幅截掉 |
| ④ 电流 | 电流 + 绿色阴影=boost 生效 | 电流水平 vs 堵转电流；补偿是否介入 |

**`plot_speed_stats.txt` / 控制台**：分段表（目标/时长/v均值/v_sd/台阶数/误差/误差%/duty/饱和%）、掉速事件表（跌幅/恢复/duty 峰/boost 占比/过冲）、占空比与 boost 总览。

---

## 2. 先量好三把"尺子"，否则会误判

1. **量化台阶**（表格里的"量化台阶 tick/s"，由速度值的最大公约数得到）。
   例：台阶 = 20 tick/s。**+20 tick/s 就已经是 5.9%**（目标 340）或 **0.9%**（目标 2250）——同一个绝对误差，在不同目标下的"百分比"完全不同。
2. **±2% 带 vs 一个台阶**。目标 250 时 ±2% = 5 tick/s **比一个台阶（20）还窄** → 那个转速下"是否稳定在 ±2%"这条判据**根本不可达**，别用它下结论。
3. **采样率 ≈ 100 Hz（dt ≈ 10 ms）**。比 10 ms 更短的事件看不到；掉速在一帧内完成是正常的（球接触时间远小于 10 ms）。

---

## 3. 逐项判读（7 条）

1. **稳态误差**：看分段表的"误差均值/误差%"。
   - 先换算成台阶：`|误差| / 台阶`。**≤1 个台阶就已经到极限了**，再想小只能提高分辨率。
2. **稳态抖动**：看"v_sd / 台阶数"与占空比的 sd。
   - 速度只在 1 个台阶内跳、占空比 sd ≤0.02 → 正常；
   - 速度跨 2~3 个台阶且**占空比同步大幅跳（方波）** → `kp` 相对台阶过大。
3. **加速段**：看 duty 是否长时间顶 1.0、超调多少。
   - 满占空比加速是**设计使然**（阶跃瞬间 P 项 = kp×跃幅 ≫ 1）；
   - 超调主要来自机械惯性（`τm`）与检测滞后，不是积分饱和——判据：**峰值时刻 I 项很小**。
4. **掉速/发射事件**：看事件表的跌幅、恢复时间、boost 占比、过冲。
   - 恢复期 duty 若已 100%，说明**恢复速度就是物理上限**，加大任何增益都无效；
   - 若 boost 占比 0%，说明检测阈值没抓到，恢复全靠 PI（慢）；
   - 若 boost 占比接近 100% 但**稳态也在触发**，说明阈值太低（误触发）。
5. **饱和占比**：>10% 要警惕（掉速时没有余量；且 PI 会在饱和边缘拉扯）。
6. **电压/电流**：满占空比时电流若远低于电机堵转电流（如 2 A vs 9 A）→ **反电动势限制了加速能力**，工作点已经太靠近该电压下的速度上限。
7. **积分项 I**：稳态若长期显著非零（比如一直 −0.06），说明**前馈偏了**（`kff` 过大/过小，或缺少 `kS` 静摩擦项），积分在替前馈干活。

## 4. 形状识别表（症状 → 原因 → 处理）

| 图上症状 | 真因 | 处理 |
|---|---|---|
| 速度出现"锯齿暴跌"，一帧掉到 0 又回来 | 按损坏的 `time` 列排序 | 用 `export_clean_table.py` 处理过的表（已按行序重建） |
| 稳态：转速只跳 1 格，**占空比在 0.5↔1.0 做方波** | `kp` 相对量化台阶过大 | 令 `kp × 台阶 ≤ 0.05`；或加滤波/降低 kp |
| 稳态误差去不掉，误差曲线平滑地停在某个非零值 | `ki` 太小 / `iZone` 太窄 / 前馈不足 | 先修 `kff`，再逐步加 `ki` |
| 到速后**冲过目标再慢慢回来**，I 项顶到 `maxI` | 积分饱和 | 减 `ki`/`maxI`；检查 `iZone` 是否太宽 |
| 每次换目标都拖一条几秒的尾巴 | 前馈偏，积分背着常值负载 | 重新标 `kff`（稳态 `d_ss/ω*`）；必要时加 `kS` |
| **掉速后 duty 已 1.0，速度线性慢爬** | 物理限制（反电动势；工作点接近上限） | 降工作转速 / 提母线电压 / 改传动比或电机 |
| 掉速时 duty 只到 0.8 就回来 | 补偿没触发或太弱 | 检查 `dropThreshold/dropRateThreshold`、加大 `kBoost`、确认 `boostMax` 没被卡死 |
| 恢复后**上冲 2~3 个台阶**才稳 | boost 退出偏晚 / 积分残留 | 减小 `boostDurationSec`；发射门控"进带 + 稳定 N 帧" |
| 速度以固定周期小幅振荡（1~2 台阶） | `kp` 接近临界，或检测阈值被抖动误触发 | 减 `kp`；提高 `dropRateThreshold`（≥2~3× 正常最大减速度） |
| 同一 duty 下转速随时间缓慢下降 | 电池电压跌落 / 发热 | 看母线电压；长期偏差靠 PI 补，或改电压量纲控制 |

## 5. 判据速查（好 / 可接受 / 差）

| 指标 | 好 | 可接受 | 差 |
|---|---|---|---|
| 稳态误差 | ≤1 个台阶 或 ≤1% | ≤2% 且 ≤2 台阶 | >2% 且超 2 台阶 |
| 稳态 v_sd | ≤0.5 个台阶 | ≤1 个台阶 | >2 个台阶 |
| 稳态 duty sd | ≤0.02 | ≤0.05 | >0.1 |
| 占空比饱和占比 | ≈0% | <5% | >10% |
| 加速超调 | ≤3% | ≤5% | >10% |
| 发射后恢复（到 ±2%） | <0.3 s | <0.5 s | >0.6 s |
| `kp × 一个台阶` | ≤0.02 | ≤0.05 | >0.1 |

---

## 6. 推荐判读顺序（照着走就不会乱）

1. **读尺子**：量化台阶、采样率、目标阶梯（表格第一行与分段表）。
2. **只看稳态段**：误差% → 台阶数 → duty sd。这是决定命中率的部分。
3. **看占空比分量（图②③）**：正常应由 **FF 主导**；I 长期非零 → 前馈偏；P 常非零 → 有稳态误差。
4. **看加速段**：duty=1 占比、超调%、峰值电流。
5. **看掉速事件表**：跌幅、恢复、boost 是否参与、恢复期是否饱和。
6. 用第 4 节对照表定位到具体参数，只改**一个**参数，再测一次同样工况对比。

---

## 7. 常见误判提醒

- 把**加速段**算进稳态统计 → `v_sd` 被撑大（本工具默认只取每段末尾 2 s，可用 `-tail` 调整；段太短时窗口会自动缩到段长一半）。
- 在低目标（如 250）上用 ±2% 判"是否稳定"→ 带比台阶还窄，判据不可达。
- 把**电压跌落**当成"参数变差"→ 先看母线电压与电流。
- 只看速度一条线就下结论 → 一定要同时看误差、占空比分量、boost、电流。
- 只测一次就下结论 → 每个工况至少跑 2~3 次，看中位数而不是单次极值。
