# 基础参数
- ### 转速（RPM）-> tick/s
RPM/(tick/s) = 2.14
(实际测试的大约数值)
- ### 硬件
  - #### 1、电机：REV HD Hex Motor
    - 编码器：REV HD Hex Motor 内置编码器
    - #### 相应参数
      - 电机理论最大转速：6000 RPM
      - 实际唯一一个最好电机最大稳定转速：5350 RPM -> 2500 tick/s
      - 实际两个其次电机最大稳定转速：5200 RPM -> 2429 tick/s
      - 实际一个最差电机最大稳定转速：4708 RPM -> 2200 tick/s
