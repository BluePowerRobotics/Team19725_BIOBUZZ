# 工程迭代
## 10/13
第一次进行球道验证机测试，测试过程中发现圆形胶轮在传动Nectar时会卡死和吸入困难，其原因在于用于传动Pollen的圆形胶轮在传动Nectar时会发生严重形变，导致胶轮与Nectar之间的接触面积过大，从而产生较大的摩擦力，增加了传动阻力。为了解决这一问题，工程决定将大多数传动胶轮由圆形胶轮改为辐射形胶轮，以减小接触面积和摩擦力，从而提高传动效率和稳定性。
## 10/15 
经过第二次球道验证机测试，工程确定了将大多数传动胶轮由圆形胶轮改为辐射形胶轮的方案。该方案在传动效率、稳定性和可靠性上均优于圆形胶轮方案，且在成本上也有一定优势。
# 程电迭代
## 9-10月
- 1. 对全场定位进行优化，硬件上结合使用limelight3A与pinpoint系统，使之具有自适应性，且不受场地环境影响；通过对全场定位算法的优化，对整个Hive进行方程求解，求的Hive不动结构与机器的相对位置，根据Hive不动结构的位置，反向求出机器的实际位置，能够在不同场地环境下实现稳定的定位和导航，提高了机器人的自主性和可靠性。
- 2. 针对如何控制Pollen与Nectar的吸入，防止吸入的总数量多于规则指定数量，我们通过自制压力传感器，设置在只允许单球通过的球道口，从而能够实时监测吸入的总数量，并通过控制算法进行调节，确保吸入的总数量不超过规则指定数量，提高了机器人的安全性和可靠性。
## 10/15
经过第一次Nectar分炮台验证机测试，发现本赛季对于上赛季的炮台工程设计上的迭代有着显著增强。我们还根据实际测试结果对原PIDSVA控制器进行了优化，改进了控制算法，并加入了阶跃，提高了炮台的响应速度和精度。并在再次测试中取得了良好的效果，炮台的响应速度和精度均有明显提升，实际转速稳定在目标转速的±10tick/s以内，且在连续发射过程中能够保持稳定的转速和精度。
